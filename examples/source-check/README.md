## 自己运行

需要 Python 3.11+。悟道部分只用标准库；AkShare 是可选依赖。不设置密钥或不安装 AkShare 时，对应来源标为 `not_tested`。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install akshare==1.18.94
# 在本地安全设置 WUDAO_API_KEY，不把真实密钥放进文章、截图或提交。
python check_sources.py \
  --codes 600519,000001,300750 \
  --dates 2026-09-09,2026-09-10,2026-09-11,2026-09-14,2026-09-15 \
  --output source-check.json
python -m unittest test_check_sources.py
```

默认继承网络代理配置。只有确认网络允许直连时，才增加 `--network direct`；它不会修改电脑的系统网络设置。

悟道使用 `https://stock.quicktiny.cn/api/mcp`，先初始化和发现工具，再调用只读 `kline`。API Key 的权限、额度和费用以自己的控制台为准。没有密钥时不会偷偷使用他人的账号。

## 检查了什么

1. 三只股票是否齐全，日期是否与给定交易日列表完全一致并按顺序返回。
2. 是否有重复日期、空价格、非有限数值或非正价格。
3. 最低价是否不高于开盘/收盘价，最高价是否不低于开盘/收盘价。
4. 悟道返回的复权口径与质量告警；AkShare 请求明确使用不复权。
5. 仅当两边都通过上述检查时，按股票、日期逐个比对四个价格，绝对容差为 0.01 元。结果相同也不能证明底层来源独立。

输出只保留公开样本的日期、股票代码、价格、请求参数、检查状态和错误类型，不保存密钥、会话头或私人观察池。脚本没有额外重试，第三方库可能有自己的重试；每只 AkShare 样本用独立进程并设 45 秒上限。它是小型验收工具，不是持续监控服务。

## 选型时如何使用

想让 Agent 查询 A股并整理盘后复盘，可以先用悟道 MCP 做接入验收；已有 Tushare 数据资产时，也应评估其[官方 MCP](https://tushare.pro/document/1?doc_id=463)。需要自己编写 Python 数据链路，可以参考 [AkShare 文档](https://akshare.akfamily.xyz/data/stock/stock.html)。不同方案先跑同一任务，再讨论预算、权限、维护成本和授权，而不是由一次连接失败决定排名。
