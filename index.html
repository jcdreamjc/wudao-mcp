把 A股数据交给 AI Agent 稳定调用

悟道数据 MCP Server 面向 WorkBuddy、Codex、Claude、Cursor、豆包、扣子、OpenClaw、Hermes 和自建 Agent，提供 68 个 A股数据工具，覆盖股票行情、指数/ETF/可转债、涨停梯队、集合竞价、题材热度、资金流向、公司事件/风险日历、宏观财经日历、短线催化日历、基本面、官方披露、海外披露、工作流和自选股管理。Agent 通过 tools/list 发现 schema，再用 tools/call 获取结构化结果。

为什么用 MCP

MCP 让智能体不再依赖粘贴网页、手写接口说明或临时脚本。工具 schema、参数、调用结果和错误都通过统一协议暴露，适合持续运行的投研、复盘和监控工作流。

工具发现

Agent 可以自己选工具

支持 initialize、tools/list、tools/call。客户端能动态读取工具定义，减少 prompt 里硬塞接口文档。

结构化结果

返回数据更适合推理

行情、梯队、资金、板块、财务和股东结构都以结构化 JSON 返回，方便 AI 汇总、比较、排序和继续调用。

统一权限

和 REST 共用一套能力

MCP、OpenClaw REST 和内部 Agent Chat 都来自同一套 Capability Registry，共用 API Key、权限、限流和调用统计。

MCP Profiles

默认推荐只接入一个稳定 MCP Server，由 Agent 根据用户问题自动选择工具。需要降低工具面或做专项工作流时，也可以使用 profile 收敛能力范围。

Profile Endpoint 工具面 适用方向
default / all https://stock.quicktiny.cn/api/mcp 68 个工具 默认推荐入口。覆盖行情、指数/ETF/转债、涨停、资金、题材、公告互动、事件日历、集合竞价、海外披露、工作流和自选股管理。
workflows https://stock.quicktiny.cn/api/mcp?profile=workflows 工作流工具 适合让 Agent 先跑市场复盘、个股研究、涨停复盘等高层工作流，再按需钻取原子数据。
short_term / stock_research / theme_research / auction_review https://stock.quicktiny.cn/api/mcp?profile=short_term 场景子集 用于短线看盘、个股研究、题材研究或集合竞价复盘等专项 Agent，减少无关工具暴露。

MCP 配置

在连板天梯开发者控制台创建 API Key 后，推荐只配置一个稳定 HTTP MCP Server。Codex、Cursor、Claude Code 等支持 MCP 的客户端可以让 Agent 在工具发现层自行选择。

mcp.jsonstable http
{
  "mcpServers": {
    "wudao": {
      "url": "https://stock.quicktiny.cn/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

协议调用示例

curlJSON-RPC
# 查看 manifest
curl -s "https://stock.quicktiny.cn/api/mcp/manifest"

# 列出工具
curl -s -X POST "https://stock.quicktiny.cn/api/mcp" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $LB_API_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

# 调用基本面估值快照
curl -s -X POST "https://stock.quicktiny.cn/api/mcp" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $LB_API_KEY" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"valuation_snapshot","arguments":{"code":"贵州茅台"}}}'

REST fallback

如果当前客户端还不能接 MCP，可以把 API Key 放入环境变量，使用 OpenClaw REST 兼容入口。适合自动化脚本、内部服务和 CI 任务。

export LB_API_KEY="YOUR_API_KEY"
export LB_API_BASE="https://stock.quicktiny.cn/api/openclaw"

curl -s -H "Authorization: Bearer $LB_API_KEY" \
  "$LB_API_BASE/fundamental/valuation?code=600519"

主要应用场景

盘后复盘

读取涨停梯队、封板率、热门板块、资金流和市场简报，让 Agent 输出市场情绪、主线题材和风险点。

短线盯盘

结合冲板、封板事件、集合竞价、热榜和异动检测，构建自动提醒或盘中观察列表。

个股投研

先用搜索和 K 线定位标的，再补充龙虎榜、研报、估值、财务摘要和股东结构，形成个股研究上下文。

策略过滤

短线强势信号之后再调用基本面 profile，过滤估值、盈利质量或股东结构明显异常的标的。

FAQ

面向 GitHub Pages、搜索引擎和 AI 引用场景的简短说明。

这是通用 MCP 框架吗？

不是。它是股票投研垂直 MCP Server，核心优势是工具语义、字段和数据源围绕 A股投研设计，而不是让开发者自己把通用接口再包装成 Agent tool。

工具多会影响短线 Agent 吗？

默认入口会暴露完整能力，但 Agent 会根据用户问题选择合适工具。需要专项收敛时，可使用 short_term、stock_research、theme_research、auction_review 或 workflows profile。

怎么拿 API Key？

进入 连板天梯开发者控制台 创建 API Key。请求头统一使用 Authorization: Bearer YOUR_API_KEY。
