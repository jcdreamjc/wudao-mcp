为什么用 MCP

MCP 让智能体不再依赖粘贴网页、手写接口说明或临时脚本。工具 schema、参数、调用结果和错误都通过统一协议暴露，适合持续运行的投研、复盘和监控工作流。

工具发现

Agent 可以自己选工具

支持 initialize、tools/list、tools/call。客户端能动态读取工具定义，减少 prompt 里硬塞接口文档。

结构化结果

返回数据更适合推理

行情、梯队、资金、板块、财务和股东结构都以结构化 JSON 返回，方便 AI 汇总、比较、排序和继续调用。

统一权限

和 REST 共用一套能力

MCP、OpenClaw REST 和内部 Agent Chat 都来自同一套 Capability Registry，共用 API Key、权限、限流和调用统计。

MCP Profiles

工具不应该一次性全部塞给所有 Agent。悟道数据按 profile 拆分能力，让短线 Agent 保持专注，也让基本面研究可以单独接入。

Profile Endpoint 工具数 适用方向
short_term https://stock.quicktiny.cn/api/mcp?profile=short_term 25 短线看盘、涨停梯队、资金板块、异动检测、市场情报。默认不带 profile 时等同短线工具集。
fundamental https://stock.quicktiny.cn/api/mcp?profile=fundamental 3 估值快照、财务摘要、股东结构。适合中线投研、质量过滤和基本面核验。
all https://stock.quicktiny.cn/api/mcp?profile=all 28 需要一个 Agent 同时处理短线和基本面任务时使用。普通短线任务不建议默认使用全量。

工具能力

当前能力分为行情、涨停板、资金分析、市场情报和基本面五组。工具名称就是 MCP tools/call 的 name。

stock_search kline minute_data stock_rank market_overview trading_calendar

涨停板与情绪

anomaly_detection capital_flow sector_analysis concept_ranking concept_stocks

wudao-intel

wudao-fundamental

基本面研究

MCP 配置 调用示例 REST fallback 应用场景 FAQ

MCP 配置

在连板天梯开发者控制台创建 API Key 后，将短线和基本面拆成两个 MCP server。Codex、Cursor、Claude Code 等支持 MCP 的客户端可以让 Agent 在工具发现层自行选择。

mcp.jsonprofiles
{
  "mcpServers": {
    "wudao-short-term": {
      "url": "https://stock.quicktiny.cn/api/mcp?profile=short_term",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    },
    "wudao-fundamental": {
      "url": "https://stock.quicktiny.cn/api/mcp?profile=fundamental",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

协议调用示例

curlJSON-RPC
# 查看 fundamental manifest
curl -s "https://stock.quicktiny.cn/api/mcp/manifest?profile=fundamental"

# 列出短线工具
curl -s -X POST "https://stock.quicktiny.cn/api/mcp?profile=short_term" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $LB_API_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

# 调用基本面估值快照
curl -s -X POST "https://stock.quicktiny.cn/api/mcp?profile=fundamental" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $LB_API_KEY" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"valuation_snapshot","arguments":{"code":"贵州茅台"}}}'

REST fallback

如果当前客户端还不能接 MCP，可以把 API Key 放入环境变量，使用 OpenClaw REST 兼容入口。适合自动化脚本、内部服务和 CI 任务。

export LB_API_KEY="YOUR_API_KEY"
export LB_API_BASE="https://stock.quicktiny.cn/api/openclaw"

curl -s -H "Authorization: Bearer $LB_API_KEY" \
  "$LB_API_BASE/fundamental/valuation?code=600519"

主要应用场景

盘后复盘

读取涨停梯队、封板率、热门板块、资金流和市场简报，让 Agent 输出市场情绪、主线题材和风险点。

短线盯盘

结合冲板、封板事件、集合竞价、热榜和异动检测，构建自动提醒或盘中观察列表。

个股投研

先用搜索和 K 线定位标的，再补充龙虎榜、研报、估值、财务摘要和股东结构，形成个股研究上下文。

策略过滤

短线强势信号之后再调用基本面 profile，过滤估值、盈利质量或股东结构明显异常的标的。

FAQ

面向 GitHub Pages、搜索引擎和 AI 引用场景的简短说明。

这是通用 MCP 框架吗？

不是。它是股票投研垂直 MCP Server，核心优势是工具语义、字段和数据源围绕 A股投研设计，而不是让开发者自己把通用接口再包装成 Agent tool。

工具多会影响短线 Agent 吗？

不会强制影响。推荐把短线任务接 short_term profile，把基本面任务接 fundamental profile。工具发现层只读对应集合。

怎么拿 API Key？

进入 连板天梯开发者控制台 创建 API Key。请求头统一使用 Authorization: Bearer YOUR_API_KEY。
